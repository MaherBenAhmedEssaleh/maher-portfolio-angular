# Maher Portfolio — Angular

Portfolio professionnel moderne, responsive et animé pour Maher Ben Ahmed Essaleh.

## Installation
```bash
npm install
npm start
```
Ouvrir http://localhost:4200

## Personnalisation
- Remplacer `src/assets/images/portrait-placeholder.jpg` par votre photo.
- Ajouter les captures dans `src/assets/projects/` et modifier le tableau `projects` dans `src/app/app.component.ts`.
- Remplacer le CV par `src/assets/Maher-Ben-Ahmed-Essaleh-CV.pdf`.
- Modifier les articles dans le tableau `posts`.
- Le formulaire est une interface prête à connecter à votre API ou Formspree.

## Build
```bash
npm run build
```
